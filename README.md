# DSH mods

Моды (плагины-бандлы) для **DeepSeek Harness** — локальные расширения UI и
поведения DSH, которые мы сделали для себя и делимся как есть.

*Unofficial plugins (mods) for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).
Each mod is a self-contained local bundle; install a mod folder through DSH's
Plugins page. Not affiliated with DeepSeek.*

## Что внутри

| Мод | Что делает | Где видно |
|---|---|---|
| [`session-cost`](session-cost) | Оценочная стоимость текущей сессии и окно с балансом DeepSeek: пополнения и бонусы, ссылки на пополнение/использование, индикатор пиковых часов | Кнопка-текст в полосе под полем ввода (рядом с индикатором контекста); клик открывает окно |

У каждого мода своя папка и своя документация:

- `README.md` — что делает, как работает, ограничения (это же описание показывается
  на странице плагина в DSH);
- `AGENTS.md` — детали реализации: источники данных, константы, проверки, история
  решений и известных багов (память для агента и для человека, который будет
  дописывать мод).

## Требования

- DeepSeek Harness **0.2.x** (проверено на `0.2.2-rc.3`, Desktop-сборка).
- Мод `session-cost` рассчитан на профиль с включённым аккаунтом DeepSeek
  (для баланса) и штатным `dsh-token-meter` (для расхода токенов). Без аккаунта
  кнопка стоимости продолжает работать, окно сообщает об отсутствии доступа.

## Установка

Каждый мод ставится отдельно, как локальный бандл — репозиторий не нужно
подключать целиком.

### Через интерфейс

1. Склонируйте репозиторий (или скачайте нужную папку).
2. В DSH откройте **Plugins** → **Add plugin** и укажите папку мода,
   например `dsh-mods/session-cost`.
3. Включите появившийся бандл, если он не включён, и обновите страницу.

### Через агента DSH

```
plugin_manager install_bundle, target = <абсолютный путь к папке мода>
```

### Обновление и удаление

Правки файлов мода подхватываются без переустановки: папка подключается
символической ссылкой в профиль. Обновление — `git pull`; удаление — **Plugins** →
удалить бандл (файлы в репозитории остаются).

## Разработка

- Конвенции, окружение и подводные камни — в [`AGENTS.md`](AGENTS.md).
  Файлы памяти лежат в репозитории намеренно: и агент, и человек работают по ним.
- Офлайн-проверка мода (нужен запущенный DSH, скрипт использует его Electron как Node):

  ```powershell
  pwsh -File tools/run-check.ps1 -Path session-cost/test/check.mjs
  ```

  Проверка не требует браузера: она загружает `client.js` с заглушками React и
  Cordis и проверяет рендер, расчёты, словари и ветки состояний.
- Живая проверка: `cordis_inspect_query` → клиентский `Slots.listSubTree` →
  запись мода в слоте должна быть `active: true`.

### Память обновляется вместе с кодом

Память проекта — часть изменения, и это проверяется автоматически:

- локальный хук `tools/git-hooks/pre-push` блокирует пуш, если изменён файл мода
  без правки `AGENTS.md` этого мода, если появился/пропал мод без правки таблицы
  модов, или если изменён `tools/`/`.github/` без правки корневого `AGENTS.md`;
- та же проверка идёт в GitHub Actions (`.github/workflows/memory-check.yml`),
  поэтому правило работает и в клоне без хуков.

Включить хук в своём клоне: `pwsh -File tools/enable-hooks.ps1`.
Осознанный обход: `SKIP_MEMORY_CHECK=1 git push`.

## Ограничения

- Моды неофициальные и используют публичные точки расширения DSH; при обновлении
  DSH часть API может измениться.
- `session-cost` показывает **оценку** стоимости: тарифы — константа в коде мода
  (пиковые ставки DeepSeek V4.1 Flash, USD), непиковые часы вдвое дешевле, но
  пересчёт по фактическому времени запросов не делается. Пиковые окна —
  01:00–04:00 и 06:00–10:00 UTC, понедельник–пятница; праздники КНР не учитываются.
- Внешний вид модов проверялся в DSH Desktop; в других темах/разрешениях
  возможны косметические расхождения.
