# DSH mods — память проекта

Проект — набор локальных модов (бандлов плагинов) для **DeepSeek Harness (DSH)**.
Каждый мод живёт в своей папке, ставится в профиль как локальный пакет и меняет
только то, что заявлено в его памяти.

**Вся память проекта — только в этом репозитории.** Не полагайся на память
прошлых чатов и на этот файл как на «снимок»: перед работой читай корневую память
и `AGENTS.md` соответствующего мода, после работы — обновляй их.

Этот файл публичный: конвенции, структура и правила. Всё специфичное для
конкретной машины (пути установки DSH, имя профиля, адрес GUI, чем запускать
скрипты, доступ к GitHub) живёт в локальном оверлее `AGENTS.local.md`, который
DSH читает дополнительно и который в git не попадает.

## Структура

```
AGENTS.md              ← этот файл: общая память, конвенции, правила
AGENTS.local.md        ← локальный оверлей: окружение и доступы (в git не входит)
LICENSE                ← MIT
README.md              ← публичное описание репозитория
.gitattributes         ← LF-нормализация переводов строк
.github/workflows/     ← проверка памяти на стороне GitHub
tools/                 ← общие инструменты репозитория (не моды)
  run-check.ps1        ← прогон офлайн-проверки мода через Electron-Node
  check-memory.sh      ← правило «память вместе с кодом» для хука и CI
  check-memory.ps1     ← тот же прогон из PowerShell (выбирает Git Bash)
  git-hooks/pre-push   ← блокирует пуш без обновлённой памяти
  enable-hooks.ps1     ← включает хук в текущем клоне
<mod>/                 ← один мод = одна папка = один бандл
  AGENTS.md            ← память мода: зачем, как устроено, грабли, проверки
  package.json         ← манифест бандла + секция dsh.client
  cordis.patch.yml     ← строка(и) Host-плагина в Loader
  index.js             ← Host-половина (может быть пустой)
  client.js            ← браузерная половина (формат window.__ModuleLoader__)
  locale/en.json, locale/ru.json  ← meta.title / meta.description для Plugins
  icon.svg             ← иконка мода (36×36)
  README.md            ← пользовательское описание (страница деталей плагина)
  test/check.mjs       ← офлайн-проверка (если у мода есть логика/UI)
```

Имя пакета мода: `@local/<папка>`. Папка и имя пакета совпадают.

## Окружение

Перед работой прочитай `AGENTS.local.md` — там фактическое окружение этой машины.
Если файла нет (свежий клон), собери факты сам, не угадывая: переменные
`$env:DSH_PROFILE`, `$env:DSH_PROFILE_DIR`, `$env:DSH_INSTALL_DIR`,
`$env:DSH_NODE_EXECUTABLE`, адрес GUI из контекста текущей сессии.

Общее для любого окружения:

- моды ставятся в **профиль** пользователя, а не в установку DSH;
- установка локальной папки подключает её символической ссылкой, поэтому правки
  файлов не требуют переустановки;
- скрипты репозитория запускаются Node из состава DSH (Electron в режиме
  `ELECTRON_RUN_AS_NODE=1`), потому что только он умеет читать `app.asar`.

## Как установить / обновить мод

1. Новый мод: `plugin_manager install_bundle` с абсолютным путём к папке мода.
   Установка сама добавляет зависимость и строку бандла в профиль.
2. Правки существующего мода: файлы на диске уже актуальны. Браузерная половина
   подхватывается по HMR: обнови `LastWriteTime` у `client.js` и подожди ~8 секунд,
   затем проверь слот. Если не подхватилось — обнови страницу (Ctrl+R).
3. Новый мод или правка Host-половины требуют `application: applied` и **новой
   сессии** для проверки.

## Как проверять (без браузерного управления)

- **Живая регистрация**: `cordis_inspect_query` → клиентский `Slots.listSubTree` с
  нужным слотом. Запись должна быть в `occupants` с `active: true`.
  `active: false` после правки артефакта = модуль ещё не перезагрузился или упал.
- **Офлайн-логика/UI**: `pwsh -File tools/run-check.ps1 -Path <mod>/test/check.mjs`.
  Проверка ставит заглушки React/Cordis, поэтому ловит ошибки рендера, скобок,
  `createPortal`, словарей и веток состояний без браузера.
- **Метаданные**: `plugin_manager list_bundles` — запись с `enabled`, `source`,
  строками; иконка должна быть валидным SVG/PNG ≤ 256 КиБ.
- Ограничение: **внешний вид** (контраст, реальные отступы) без браузера не
  проверить — это подтверждает человек глазами. Не выдавай установку за
  визуальную проверку.

## Правила мода

- Один мод — одна папка; не смешивай в одной папке два независимых мода.
- UI: только токены темы `--dsw-alias-*` / `--dsh-*`; не импортировать
  client-пакеты DSH (`dsh-client-ui-primitives` и т.п.); свои контролы.
- Текст интерфейса — через клиентский locale-сервис (`ctx.locale.register` +
  `locale: NS` в регистрации слота), словари en + ru.
- Ресурсы (таймеры, подписки) — внутри `apply` через `ctx.effect`, с очисткой.
- Данные только из штатных источников: проекции сессии (`useProjection`),
  Remote-методы, сервисы. Не писать свои события в лог сессии.
- Обязательная мета: `locale/*.json` с `meta.title`/`meta.description`, иконка,
  README. Без этого мод выглядит сломанным в Plugins.
- Конфигурируемые числа (тарифы, окна, лимиты) — константой с комментарием в
  коде мода и описанием в его `AGENTS.md` и README.
- Лицензия модов и репозитория — MIT.

## Чек-лист работы над модом

1. Прочитать корневой `AGENTS.md`, `AGENTS.local.md` и `AGENTS.md` мода.
2. Уточнить актуальные API через `cordis_inspect_list` / `cordis_inspect_query`
   (сервисы, события, слоты, токены темы), а не по памяти.
3. Внести правку в файлы мода.
4. Парс-проверка + `tools/run-check.ps1` (если есть тест).
5. Если модуль уже в профиле — touch `client.js` и проверить `active: true`.
6. Обновить `AGENTS.md` мода (что изменилось, новые грабли) и таблицу модов ниже.
7. Закоммитить код и память вместе; пуш проверит хук.
8. Отчитаться: где кнопка/поведение, что проверено, что осталось на глаза.

## Память при пуше

Память — часть изменения, а не отдельная задача. Это проверяется автоматически,
а не «по договорённости»:

- `tools/git-hooks/pre-push` — локальный хук, блокирует пуш;
- `.github/workflows/memory-check.yml` — та же проверка на стороне GitHub, чтобы
  правило работало и без установленных хуков (видно по красному статусу);
- обе вызывают один скрипт `tools/check-memory.sh`.

Правила проверки:

1. Изменён любой файл мода (кроме `AGENTS.md`) → в том же пуше должен быть изменён
   `AGENTS.md` этого мода.
2. Появился новый мод (папка с `package.json`) или исчез старый → в том же пуше
   должен быть изменён корневой `AGENTS.md` (таблица модов).
3. Изменено что-то в `tools/` или `.github/` → в том же пуше должен быть изменён
   корневой `AGENTS.md`.

Включить хук в свежем клоне: `pwsh -File tools/enable-hooks.ps1`
(это `git config core.hooksPath tools/git-hooks`).

Проверить вручную (то же, что сделает хук): `pwsh -File tools/check-memory.ps1`
или, из Git Bash/CI, `sh tools/check-memory.sh origin/main HEAD`.
В PowerShell `bash` — это WSL-заглушка, поэтому прямой `bash tools/check-memory.sh`
там не работает: скрипт POSIX-sh, а обёртка сама находит Git Bash.

Обойти проверку осознанно: `SKIP_MEMORY_CHECK=1 git push` или `git push --no-verify`.
Обход допустим для чисто редакционных правок, которые не меняют поведение мода;
после него память всё равно нужно привести в порядок.

## Грабли (проверено на практике)

- **`ctx.remote.<ns>` без `inject` падает**: `cannot get property "remote.account"
  without inject`. Читать namespace либо через `ctx.inject(['remote.<ns>'], …)`,
  либо через inject-free `ctx.get('remote.<ns>')`. `inject` в описании плагина
  делает всю половину неактивной, если сервиса нет.
- **`createPortal`**: контейнер должен быть `document.body`, иначе React бросает
  исключение, а слой слотов **снимает запись** — кнопка исчезает. Собирай узел в
  переменные, а тест должен требовать `container === document.body`.
- **Сдвинутая скобка в глубоком `h(...)`** ломает разметку незаметно для
  `new Function`; ловится только структурными проверками дерева.
- **`tokenUsage` бывает неизвестен**: пока провайдер не сообщил usage, проекция
  `undefined` — показывать `$0.00` нельзя, лучше не рендерить запись.
- **HMR**: после записи файла запись слота может кратко стать `active: false`;
  повторный touch возвращает её. Если артефакт прочитан в момент записи,
  страница остаётся со старым/битым модулем — помогает Ctrl+R.
- **Счётчики токенов** приходят готовыми в проекции `tokenUsage`
  (`uncachedInputTokens`, `outputTokens`, `cacheReadTokens`,
  `cacheWriteTokens`); не считать их по тексту.

## GitHub

Публичный репозиторий: **https://github.com/poznik/dsh-mods**, ветка `main`.

- Сообщения коммитов — по-английски, одна логическая правка = один коммит.
- Перед пушем: офлайн-проверки затронутых модов зелёные.
- Правка кода и обновление памяти (`AGENTS.md` мода, таблица модов ниже, этот
  файл) — в одном коммите; хук не пропустит иначе.
- Доступы и учётные данные — в `AGENTS.local.md`, не здесь.
